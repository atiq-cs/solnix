## Licence — verified, not assumed

The Intel-derived portions carry an explicit dual grant (`if_iwm.c` header):

> This file is provided under a dual BSD/GPLv2 license. **When using or redistributing this file, you may
> do so under either license.**

So the BSD option is exercisable. Stefan Sperling's / genua gmbh's OpenBSD-authored portions are ISC
("Permission to use, copy, modify, and distribute this software for any purpose…"), as is Fixup Software Ltd.'s.

⚠️ The files *do* contain the GPLv2 summary text, because that is what a dual-licence header looks like.
Grepping for "GNU General Public" returns hits — that is **not** contamination, and anyone auditing this
should read the grant rather than the grep count. Same note as `iwx/PROVENANCE.md`.

⚠️ Per the maintainer's note: iwlwifi's **`dwm` (device memory management)** portion is GPL-only and is
excluded from BSD builds. OpenBSD's `iwm` already does not include it, which is one more reason this is
the right source rather than Linux's tree.

## Hardware covered

Intel Wireless-AC **7260 … 9560** (OpenBSD `iwm(4)`). The X1 "dixi" target is an **AC 9560**,
PCI `8086:a370` subsystem `8086:0030` rev `0x10` — a CNVi device (Jefferson Peak RF on a Cannon
Lake PCH), iwlwifi device family **9000**. It is *not* an AX201, and OpenBSD `iwx(4)` has no
`a370` entry, so `iwm` is the correct driver for dixi (see `STATUS.md` rung 1).

## Firmware

Proprietary and required. OpenBSD **renames** the Intel blobs, so the names differ from Linux's.
dixi's AC 9560 uses `iwm-9000-46` (Linux `iwlwifi-9000-pu-b0-jf-b0-46.ucode`), packaged by
`pkgs/illumos/iwm-firmware.nix`.

The driver loads it via `loadfirmware(sc->sc_fwname, …)` (`upstream/if_iwm.c:717`), which opens
`firmware/iwm/<name>` on the kernel module path (`uts/common/os/firmload.c`), i.e.
`/kernel/firmware/iwm/iwm-9000-46`.

## What is here and what is NOT

* `upstream/` — the 3 upstream files, read-only. **REAL** upstream source; the reference manual
  and the input to `gen-illumos-src.py`. **Never edited.**
* The port's delta is `patches/if_iwm.illumos.patch` (reviewable) regenerated from `upstream/`
  by `gen-illumos-src.py` into `build/if_iwm_illumos.c`; the generated file is never authoritative.

Provenance of the algorithms and illumos mappings used to port this driver is recorded in
`../net80211/PROVENANCE.md` (the 802.11 stack, crypto, mbuf, kcompat adapters) and in `STATUS.md`
(the claim ladder). The licence of this port follows the repository.
