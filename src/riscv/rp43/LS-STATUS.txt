PRECISE BLOCKERS FOUND (in compile order, before any gnulib .c was linked):

  1. SYSTEM HEADERS ls.c #include <...> that the reduced libc lacks:
       termios.h        -> SHIMMED (rp43/user/ls-include/termios.h: struct
                           winsize + TIOCGWINSZ; the reduced kernel has no tty
                           ioctl, ls falls back to COLUMNS/80).
       sys/ioctl.h      -> SHIMMED (ls-include/sys/ioctl.h: ioctl() -> -1).
       setjmp.h         -> **HARD BLOCKER, NOT SHIMMED.**  ls.c uses
                           setjmp/longjmp for its qsort comparison-function
                           error recovery (the `sort_failed` jmp_buf in
                           sort_files()).  This needs a REAL riscv64
                           setjmp/longjmp (callee-saved reg + sp save/restore in
                           asm) in the libc -- a stub is not correct here (a
                           failed comparison would fall through instead of
                           unwinding).  THIS IS THE FIRST REAL BLOCKER TO FIX in
                           R-P44: add port/setjmp.S (save ra/sp/s0-s11/fs0-fs11,
                           restore + return the longjmp value) + include/setjmp.h.
       fnmatch.h        -> needs a fnmatch() (ls --ignore / --hide globs); a
                           reduced POSIX fnmatch (no FNM_* beyond the basics)
                           would suffice, but comes after setjmp.
       selinux/selinux.h, uchar.h -> already provided in cu3-include (stubs).

  2. THE ~30 GNULIB MODULES (deferred, not yet started) -- ls.c #includes:
       acl.h argmatch.h c-strcase.h dev-ino.h filenamecat.h hard-locale.h
       hash.h human.h filemode.h filevercmp.h idcache.h ls.h mbswidth.h
       mpsort.h obstack.h quote.h smack.h stat-size.h stat-time.h strftime.h
       xdectoint.h xstrtol.h xstrtol-error.h areadlink.h dircolors.h
       xgethostname.h c-ctype.h canonicalize.h statx.h
     The REAL gnulib .c for every one of these is present in the tarball at
     rp43/upstream/cu-full/coreutils-9.5/lib/ (obstack.c mpsort.c hash.c
     human.c mbswidth.c filevercmp.c filemode.c idcache.c canonicalize.c
     argmatch.c dircolors.c[generated by dircolors.hin] areadlink.c
     xgethostname.c xstrtol.c ...), so R-P44 provides them verbatim (not
     hand-written) and grows the libc for what they need (wcwidth/mbrtowc for
     mbswidth, realpath-family for canonicalize, the obstack chunk allocator).
